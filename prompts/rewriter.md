# 单句改写提示词（校验失败后的修复）

> 用途：某一句没有通过 V1–V5 校验时，带着**失败原因**和**它可以引用的原片段**，只改这一句。
> 调用方：`src/ragwriter/generate/writer.py::rewrite_sentence`（非流式）。最多两轮，仍不过由编排层删除并记入校验报告。
>
> **为什么只改一句**：整节重写会让已经通过校验的句子重新冒出问题，校验结果不再单调收敛。
> **为什么要给失败原因**：「请改正这句话」模型往往只调措辞；告诉它「15倍描述的是订单增长，不是流量增长」，
> 它才知道该改哪里。
> **为什么允许回答「无法改写」**：片段确实撑不住这句话时，硬改只会换一种方式编造。
> 这条写在 `_rules.md` 的「资料不足（改写）」段；程序把「无法改写」映射为空字符串，编排层据此删除该句。

### 各项校验的含义与修法

| 校验 | 失败意味着 | 修法 |
|---|---|---|
| V1 | 句中引用编号不在本次片段里 | 只用下面给出的片段编号 |
| V2 | 句中某个数字、年份或专名不在所引片段原文里 | 改成片段原文写法；片段里没有就删去它 |
| V3 | 数字挂错了对象（写成了同页另一个数字的标签） | 把数字挂回片段里与它配对的标签，标签用原词 |
| V4 | 句子含事实却没有引用 | 补上支持它的片段编号；没有片段支持就删去该事实 |
| V5 | 所引片段不支持本句（字面支持度过低，或判别模型判不支持） | 收窄说法，只保留片段原意能支撑的部分 |

> **不要为了过校验随手挂引用。** V4 失败时，如果没有片段真正支持这句话，就把它改成不含事实判断的过渡句，
> 或按硬约束第 4 条放弃——挂一个不相干的片段编号会被 V5 拦下，等于白改一轮。

### 改写要求

1. **只改这一句**，保持它在原文中的作用（论点、论据或过渡），长度与原句相近。
2. **不新增事实**：只能使用下面给出的原片段；不得为了「补全」而引入片段之外的内容。
3. 修复全部失败原因；没有失败的部分尽量保留原措辞。
4. 只输出改写后的这一句（含 [S编号]），不加引号、不加解释；改不对时按硬约束第 4 条处理。
